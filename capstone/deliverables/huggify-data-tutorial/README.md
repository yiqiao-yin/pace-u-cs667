# README

Please use this [repo](https://github.com/yiqiao-yin/huggify-data) to learn and go through the examples session. In the main README.md file of the repo, there is an **Examples** section. You should be able to figure it out step by step just by reading the README file. 

Make sure to use your own *OPENAI_API_KEY*  and make sure to use a PDF that is only 1-2 pages to ensure you do NOT blow up your API quota. 

The goal is to reproduce the repo steps. Please submit 1) the URL of the deliverable repo folder, and 2) a video no longer than 1 minute walk through the steps you took when learning about the *huggify-data* package.
