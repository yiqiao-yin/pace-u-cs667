# README

Please use this repo [warren-buffett-letters-from-1998-2024](https://github.com/yiqiao-yin/warren-buffett-letters-from-1998-2024) as a template. It will walk you through how to curate question-answer-reasoning dataset from a PDF or a sequence of PDFs documents.

Please learn to reproduce this and then curate your own dataset. 

You should pick a class you are taking and pick a sample chapter of textbook or notes for reproducibility. 

The submission will contain 1) the URL of the deliverable folder for the project repo, and 2) a video less than 1 minute to walk audience through your steps.
