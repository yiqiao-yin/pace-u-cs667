# README

Please go through this [repo](https://github.com/yiqiao-yin/wyn-voice) to which will walk you through how to create voices from chatbot interface. 

The goal is to reproduce this voice capability in a jupyter notebook. You can pick your favorite IDE. My recommendation is just Colab on Google. 

Your submission is 1) the deliverable folder (inside should contain the jupyter notebook you used to run the chatbot with voice capability), and 2) a video less than 1 minute to walk through what you did step by step.
